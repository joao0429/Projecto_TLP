Introdução ao CSS

CSS (Cascading Style Sheets)Folhas de Estilo em Cascata é uma linguagem de estilo usada para descrever a apresentação de documentos HTML. Enquanto o HTML estrutura o conteúdo, o CSS cuida da aparência visual.

/* Exemplo básico de CSS */
body {
  background-color: #f0f0f0;
  font-family: Arial, sans-serif;
}

Sintaxe CSS

A sintaxe CSS é composta por seletores e declarações. Cada declaração inclui uma propriedade e um valor.

Estrutura básica:
seletor {
  propriedade: valor;
}

Seletores CSS

Seletores determinam quais elementos HTML receberão os estilos definidos.

Seletor de Tipo

Seleciona elementos pelo nome da tag

p { color: blue; }

Seletor de Classe

Seleciona elementos por classe

.destaque { color: red; }

Seletor de ID

Seleciona um elemento único por ID

#menu { display: flex; }

Seletor Universal

Seleciona todos os elementos

* { margin: 0; padding: 0; }

Box Model

Todo elemento HTML é tratado como uma caixa com: conteúdo, padding, border e margin.

Conteúdo
.elemento {
  width: 300px;
  padding: 20px;
  border: 2px solid #000;
  margin: 30px;
}

Animações CSS

Crie transições suaves e animações sem JavaScript usando keyframes.

Exemplo de animação:
CSS
@keyframes rotacao {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}

.elemento {
  animation: rotacao 3s infinite linear;
}

Design Responsivo

Crie layouts que se adaptam a diferentes tamanhos de tela usando media queries.

/* Estilos para mobile */
.container {
  padding: 1rem;
}

/* Tablet */
@media (min-width: 768px) {
  .container {
    padding: 2rem;
  }
}

/* Desktop */
@media (min-width: 1024px) {
  .container {
    max-width: 1200px;
    margin: 0 auto;
  }
}
